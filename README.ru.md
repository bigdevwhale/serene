## Идея

Спокойствие — это навык, и, как любой навык, он растёт от нескольких минут практики в день.

Serene придаёт этим минутам мягкую форму: добрая мысль утром, вдох, когда всего слишком много, путешествие в тихое место, момент, чтобы представить жизнь, которую вы хотите, и пара строк о хорошем перед сном. Приложения для медитации обычно прячут большую часть этого за подпиской. Здесь всё открыто, регистрироваться не нужно, и ничто не покидает ваш телефон.

## English & Русский

Каждый экран, медитация, визуализация и аффирмация написаны на обоих языках вручную, без машинного перевода. Русские тексты гендерно-нейтральны и подходят всем. Язык переключается в **Настройки → Язык**; на Android 13+ приложение есть и в системных настройках языка.

Светлая и тёмная темы; практики всегда идут на тёмной, медленно живущей сцене.

## Скачать

APK — в **[Releases](https://github.com/bigdevwhale/serene/releases/latest)**, или debug-APK из любого [запуска CI](https://github.com/bigdevwhale/serene/actions/workflows/android.yml).
Android 8.0 (API 26) или новее.

> [!TIP]
> Для голоса на телефоне нужен офлайн-голос синтеза речи для вашего языка (обычно он есть в «Распознавании и синтезе речи Google»). **Настройки → Голос → Синтез речи** открывает нужный экран.
> На Xiaomi (MIUI / HyperOS), Huawei и некоторых других телефонах разрешите **автозапуск**, чтобы напоминания приходили вовремя.

## Приватность

Без аккаунтов, серверов, аналитики, рекламы и даже без доступа к интернету. Дневник, избранное и визуализации хранятся в локальной базе на телефоне; фото визуализаций копируются в закрытую папку приложения.
**Настройки → Резервная копия** сохраняет всё (кроме фото) в JSON-файл.

## Как устроено

- **Kotlin + Jetpack Compose**, Material 3 со своей палитрой, шрифты Inter и Lora.
- **Синтез звука в коде**: генераторы шума, фильтры и синусоиды потоком идут в `AudioTrack` (`audio/Soundscape.kt`); поющая чаша — набор медленно биющихся обертонов (`audio/Chimes.kt`). Аудиофайлов в приложении нет.
- **Android `TextToSpeech`** для голоса, фон приглушается, пока голос говорит.
- Анимированные сцены (рассвет, океан, лес, ночь, горы, луг, свет, космос) рисуются на `Canvas`.
- **Room** для практик, дневника, баланса, своих аффирмаций, избранного и визуализаций · **DataStore** для настроек · **AlarmManager** для напоминаний.

## Сборка

```bash
git clone https://github.com/bigdevwhale/serene.git
cd serene
./gradlew testDebugUnitTest      # юнит-тесты
./gradlew installDebug           # app.serene.dev рядом с основным приложением
./gradlew installDebug -Pdemo    # app.serene.demo с придуманным дневником и визуализациями
```
